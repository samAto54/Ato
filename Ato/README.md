# Ato – AI Agent Project

## What Ato is

Ato is a personal AI agent designed to assist users with learning, productivity, and problem-solving. It can understand natural language, answer questions, and in future versions, perform actions like searching, remembering information, and interacting with external tools.

## Vision

The vision of Ato is to become a smart, reliable digital assistant that helps users (especially students and developers) work faster, learn better, and automate simple tasks.

Over time, Ato will evolve from a basic chatbot into a fully functional AI agent capable of:
- Remembering user preferences and past conversations
- Connecting to APIs and external tools
- Helping with academic and technical learning
- Assisting in cybersecurity and software development tasks

## Technologies (initial stage)

- JavaScript (core logic)
- Node.js (backend)
- HTML/CSS (basic interface)
- OpenAI API (AI reasoning)
- Supabase (database and memory storage)
- GitHub (version control)
